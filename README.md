# 탕탕 슈터 — 뱀서라이크 웹 게임 스타터

한 손으로 즐기는 **뱀서라이크(탕탕에이스류) 슈팅** 웹 게임 스타터입니다.
빌드 도구도, 패키지도, 프레임워크도 없이 `index.html` + `style.css` + `game.js` 세 파일만으로
아이폰/안드로이드 브라우저에서 바로 돌아갑니다.

**▶ 바로 플레이: https://qkehehd56-hue.github.io/tangtang-starter/**

---

## 조작

| | 모바일 | PC |
| --- | --- | --- |
| 이동 | **화면 아무 곳이나 드래그** (그 자리에 가상 조이스틱이 생김) | `WASD` / 방향키 |
| 공격 | 자동 (가장 가까운 적에게 자동 조준) | 자동 |
| 레벨업 선택 | 카드 탭 | `1` `2` `3` |
| 일시정지 | 우측 하단 ❚❚ 버튼 | `ESC` |

- 화면은 `100dvh`로 꽉 채우고 `touch-action: none`으로 스크롤·확대·당겨서 새로고침을 막았습니다.
- 세이프 에어리어(노치·홈 인디케이터)를 `env(safe-area-inset-*)`로 피합니다.

## 게임 규칙

- **목표: 3분(180초) 생존** → `STAGE CLEAR`
- 20초마다 **웨이브**가 올라가고 적이 늘어납니다.
- 18초부터 **엘리트**(보라), 60초·140초에 **보스**(청록)가 등장합니다.
- 적을 처치하면 **경험치 젬**을 떨구고, 일정 범위 안에 들어오면 자석처럼 빨려와 자동 획득됩니다.
- 레벨업하면 게임이 멈추고 **스킬 카드 3장** 중 하나를 고릅니다.

### 업그레이드 10종

| 카드 | 효과 | 최대 |
| --- | --- | --- |
| 🔫 탄환 수 +1 | 발사 탄환 수 증가(부채꼴) | 4 |

| 💥 공격력 | 탄환 피해량 +22% | 6 |
| 🛰️ 수호구 | 회전하는 오비탈 추가 | 4 |
| 🧲 자석 범위 | 젬 흡수 범위 +40% | 4 |
| 👟 이동 속도 | 이동 속도 +12% | 4 |
| ❤️ 최대 체력 | 최대 체력 +25 & 즉시 회복 | 5 |
| 🎯 관통 | 적 1명 추가 관통 | 3 |
| ⭕ 탄환 강화 | 탄환 크기·피해량 증가 | 3 |
| 🌿 재생 | 초당 체력 1 회복 | 3 |

## 파일 구조

```
tangtang-starter/
├── index.html   # 화면 골격: 캔버스, HUD, 시작/레벨업/일시정지/결과 오버레이
├── style.css    # 모바일 우선 레이아웃, HUD, 카드, 결과 화면
├── game.js      # 게임 루프 전체 (입력 → 업데이트 → 렌더 → UI)
└── README.md
```

`game.js` 안의 순서: 상수 → DOM → 입력 → 상태 초기화 → 업데이트 → 렌더 → UI → 루프.
게임 오브젝트는 전부 평범한 객체/배열이라 어디서든 값을 바꿔 실험할 수 있습니다.

### 로컬에서 실행

```bash
# 이 폴더에서
python3 -m http.server 8000
# 그다음 브라우저에서 http://localhost:8000
```

`index.html`을 파일로 직접 열어도 되지만(별도 요청 없음) 로컬 서버가 편합니다.

### 콘솔 디버그 훅

브라우저 콘솔에서 `TT` 객체로 상태를 확인하고 테스트할 수 있습니다.

```js
TT.state        // 'title' | 'playing' | 'levelup' | 'paused' | 'over'
TT.player       // 플레이어 스탯 (speed, damage, fireRate, pickup ...)
TT.enemies      // 현재 적 배열
TT.game         // 시간·킬·웨이브·스폰 타이머
TT.god()        // 무적(체력 9999)
TT.levelUp(3)   // 레벨업 카드 3번 연속 띄우기
TT.spawn('boss')// 보스 즉시 소환
TT.killAll()    // 화면의 적 전부 처치
```

## Claude Code Pro로 이어서 만들기

이 스타터는 **"한 번에 100줄씩, 실행해서 확인하고 넘어가기"**에 맞춰져 있습니다.
아래 순서대로 한 기능씩 붙이면 자연스럽게 커집니다.

### 1. 먼저 읽힐 맥락을 정리해 두기

Claude Code에 작업을 시킬 때 이렇게 시작하면 편합니다.

```
이 저장소는 의존성 없는 Canvas 2D 뱀서라이크 스타터야.
game.js 구조: 상수 → 입력 → update() → render() → HUD.
먼저 game.js를 읽고, 지금 업그레이드가 어떻게 정의돼 있는지(UPGRADES 배열)와
적 타입 정의(TYPES)를 요약해 줘. 코드는 아직 건드리지 마.
```

핵심 확장 지점은 딱 세 군데입니다.

| 확장하고 싶은 것 | 손볼 곳 |
| --- | --- |
| 새 스킬/업그레이드 | `UPGRADES` 배열 + `applyUpgrade()` switch |
| 새 적/보스 패턴 | `TYPES` + `spawnEnemy()` + `updateEnemies()` |
| 새 무기/탄환 | `fire()`, `updateBullets()`, `drawBullets()` |

### 2. 무기 진화 (가장 재미있는 다음 단계)

뱀서라이크의 핵심 재미는 "기본 무기 + 조건 충족 → 진화 무기"입니다.

- 플레이어에 `weapon` 필드를 추가하고 `fire()`를 무기별로 분기하세요.
  - 예: `pistol`(기본) → `shotgun`(근거리 5발) → `laser`(관통 빔)
- 진화 조건은 업그레이드 조합으로: `bulletCount >= 3 && pierce >= 1` → 다음 레벨업 카드에
  "진화: 레이저"를 넣는 식입니다. `rollCards()`에 특수 카드를 끼워 넣으면 됩니다.
- Claude Code 프롬프트 예시:
  ```
  UPGRADES에 'evolve_laser'(조건: multi 3 + pierce 1) 카드를 추가해 줘.
  조건을 만족할 때만 rollCards()에 등장하고, 선택하면 fire()가 관통 빔을 쏘게 해 줘.
  기존 밸런스는 유지하고, 변경 후 TT.spawn('elite')로 테스트하는 방법도 README에 추가해 줘.
  ```

### 3. 보스 패턴 만들기

지금 보스는 "크고 단단한 적"입니다. 여기에 패턴을 넣으려면 `updateEnemies()` 안에서
`e.type === 'boss'`일 때 타이머(`e.cd`)로 공격을 발생시키면 됩니다.

- 돌진: 일정 시간마다 플레이어 방향으로 `e.speed`를 3배로 0.4초간.
- 탄막: `bullets` 배열에 **적 탄환**을 넣고 `owner: 'enemy'` 플래그로 구분해 플레이어와 충돌시킵니다.
- 소환: `spawnEnemy('grunt')`를 보스 주변에서 4마리.

### 4. 상점 / 결제 UI

웹 게임에서 "상점"은 보통 두 가지입니다. 둘 다 지금 구조에 얹기 쉽습니다.

**(a) 게임 내 코인 상점** — 처치 시 `game.coins`를 쌓고, 게임 오버 화면에 상점 버튼을 둡니다.

```
결과 화면에 '상점' 버튼을 추가하고, game.coins로 영구 업그레이드(시작 체력 +10 등)를
사는 화면을 만들어 줘. 영구 업그레이드는 localStorage에 저장해.
```

**(b) 실제 결제(후원/아이템)** — 국내에서는 결제 연동이 필요하므로 서버와 사업자 등록이
필요합니다. 프로토타입 단계에서는 **결제 UI만 목업**으로 만들고 실제 청구는 붙이지 마세요.
실결제를 붙일 때는 토스페이먼츠·포트원(아임포트) 같은 PG의 **테스트 키**로만 확인하는 것을 권합니다.

### 5. 저장 / 이어하기

- `localStorage`에 최고 기록(생존 시간·킬·레벨)을 저장해 결과 화면에 "최고 기록"을 표시하세요.
- 아이폰에서 앱처럼 쓰려면 `manifest.json` + `apple-mobile-web-app-*` 메타태그로 **PWA 홈 화면 추가**를
  붙일 수 있습니다. (이미 관련 메타태그는 들어가 있습니다.)

### 6. 밸런스 튜닝은 상수만 건드리기

`game.js` 맨 위에 모아 두었습니다.

```js
const GOAL_TIME   = 180;   // 클리어까지 생존 시간(초)
const WAVE_SEC    = 20;    // 웨이브 길이
const MAX_ENEMIES = 300;   // 동시 적 수 상한(모바일 프레임 보호)
const JOY_MAX     = 62;    // 조이스틱 반경
```

적 체력/속도는 `spawnEnemy()`의 `hpMul`, `spMul`, 스폰 속도는 `updateSpawn()`의
`Math.max(0.17, 0.82 - game.time * 0.0075)`에서 조절합니다.

### 7. 성능 팁 (모바일)

- 프레임당 `ctx.save()/restore()`와 `shadowBlur`는 비쌉니다. 지금은 그림자 없이 그리고,
  적은 도형으로만 그립니다. 이펙트를 늘릴 때 `shadowBlur`는 화면 전체에 쓰지 마세요.
- 적 수는 `MAX_ENEMIES`로 제한되어 있고, 겹침 계산은 O(n²)입니다. 300마리까지는 괜찮지만
  500마리 이상 늘리려면 공간 해시(그리드)로 바꾸세요.
- `devicePixelRatio`는 2로 캡을 걸어 두었습니다(iPhone 3x에서 픽셀 수를 44% 절약).

## 배포 (GitHub Pages)

이 저장소는 `main` 브랜치 루트를 그대로 Pages로 서빙합니다. 빌드 과정이 없습니다.

```bash
git add .
git commit -m "feat: 게임 로직 수정"
git push
# 1~2분 뒤 https://qkehehd56-hue.github.io/tangtang-starter/ 에 반영
```

Pages 설정은 저장소 **Settings → Pages → Source: Deploy from a branch → main / (root)** 입니다.
CLI로 다시 켜야 할 때:

```bash
gh api -X POST repos/qkehehd56-hue/tangtang-starter/pages \
  -f source[branch]=main -f source[path]=/
```
